# Icon attribution

The `gramps-*.svg` icons in this directory are copied unmodified from the
[Gramps](https://github.com/gramps-project/gramps) desktop application
(`images/hicolor/scalable/actions/`).

Per Gramps' own `images/LICENSE`: most of this artwork is from the
[Tango Project](http://tango.freedesktop.org/) or derived from it, released
under the [Creative Commons Attribution-ShareAlike 2.5](
https://creativecommons.org/licenses/by-sa/2.5/) license.

`chat-message.svg` is original artwork for this project (Messages view) --
Gramps' own icon theme has no chat/message glyph to source from, so it
doesn't follow the `gramps-*.svg` naming or Tango style of the icons above.

`gramps-connect-logo.svg` is also original artwork: this app's own mark,
and the reason the row above no longer includes a `gramps-logo.svg`. That
file was Gramps' application icon (`org.gramps_project.Gramps.svg`), and
standing in as this app's logo it claimed an identity that isn't ours --
a separate question from the licence, which the attribution above would
have satisfied either way. The new mark keeps the family resemblance (the
same pedigree-chart idea, cut from seven boxes to three) in this app's own
blue, and is small enough to still read at favicon size. Its badged form,
used for the favicon, is `app/public/favicon.svg`.
